# cogdex-ai.github.io

Website for Cogdex, served at https://cogdex-ai.github.io by GitHub Pages.

Plain HTML and CSS, no build step. Pushing to `main` publishes the site.

- **Beta signup link:** set `SIGNUP_URL` at the top of `main.js`. While it is empty, the page says invites open soon.
- **LinkedIn / social preview:** `og.png` (1200×627) is rendered from `_og/card.html`. Folders starting with `_` are not published.
